# World Theme Explorer

当前版本聚焦“太空中看地球”的视觉体验，并开始进入动物主题 MVP：在地球场景上方叠加明星物种卡片库。

## 当前能力
- 沉浸式地球视图（太空风格）
- 高质量地球底图（昼间纹理 + 起伏 + 镜面反射）
- 云层与大气辉光效果
- 动物主题 MVP：30 个明星物种卡片
- 卡片字段：中文名、英文名、拉丁学名、分类、简介、IUCN 风险色卡

## 启动项目
```bash
npm install
npm run dev
```

## MVP 数据说明
- 数据文件：`src/data/species.js`
- 当前为精选样本库，后续将接入 GBIF / IUCN 等公开来源扩充分布数据
