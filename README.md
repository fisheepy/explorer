# World Theme Explorer

当前版本聚焦“太空中看地球”的视觉体验：使用 Three.js 渲染高质量地球贴图、云层、大气辉光与星空背景。

## 当前能力
- 沉浸式全屏地球视图（无左右框图）
- 高质量地球底图（昼间纹理 + 起伏 + 镜面反射）
- 云层与大气辉光效果
- 星空背景与柔和光照
- 交互控制：拖拽旋转、滚轮缩放

## 启动项目
```bash
npm install
npm run dev
```

## 地图与纹理来源
- 地球/云层/星空纹理：Three.js 官方示例公开纹理
