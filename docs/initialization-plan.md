# World Theme Explorer 初始化方案

## 1. 产品目标
- 构建“太空视角地球”作为核心视觉体验。
- 后续在该视觉基底上叠加主题探索数据（动物、植物、建筑等）。

## 2. 当前实现（视觉优先）
- 全屏 3D 地球场景（Three.js + OrbitControls）
- 高质量地球贴图（颜色、起伏、镜面）
- 云层、星空背景、大气辉光
- 统一中文界面文案

## 3. 当前架构
- `src/GlobeScene.jsx`：地球渲染、光照、材质、交互与资源清理
- `src/App.jsx`：极简页面结构（标题 + 地球）
- `src/styles.css`：沉浸式深色视觉样式

## 4. 后续迭代建议
1. 引入国家/地区高亮图层（按主题动态渲染）。
2. 增加“点击地球显示信息”的最小交互面板（非固定侧栏）。
3. 逐步加入时间维度与探索任务玩法。
