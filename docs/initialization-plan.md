# World Theme Explorer 初始化方案

## 1. 产品目标
- 构建“太空视角地球”作为核心视觉体验。
- 在地球上叠加主题探索层，先从动物分布与物种知识卡片切入。

## 2. 当前实现（MVP Step 1）
- 全屏 3D 地球场景（Three.js + OrbitControls）
- 高质量地球贴图（颜色、起伏、镜面）+ 云层 + 大气辉光
- 明星物种卡片库（30 个）
- 每张卡片包含：中英文名、拉丁名、分类、简介、濒危风险色卡

## 3. 当前架构
- `src/GlobeScene.jsx`：地球渲染、光照、材质、交互与资源清理
- `src/data/species.js`：物种数据与 IUCN 风险映射
- `src/App.jsx`：MVP 页面编排与卡片展示
- `src/styles.css`：沉浸式视觉与卡片面板样式

## 4. MVP 路线（动物主题）
1. **Step 1（已完成）**：建立 30 个明星物种卡片基础数据库。
2. **Step 2**：为每个物种增加地理分布点位/范围字段并与地球联动。
3. **Step 3**：增加筛选器（分类、风险等级、地区）和搜索。
4. **Step 4**：接入公开来源（GBIF / IUCN）做批量数据扩展与更新。
