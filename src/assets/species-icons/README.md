# Species SVG Icons

Primary naming rule:

- `species-<species-id>.svg`

Optional variants:

- `species-<species-id>--badge.svg`
- `species-<species-id>--mono.svg`
- `species-<species-id>--outline.svg`

The `<species-id>` must match `src/data/species.js`.
The visual system is documented in `docs/icon-system.md`.
